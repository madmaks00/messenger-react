Политика конфиденциальности Messenger Storage

Дата обновления: 14 октября 2026 года.

Эта страница описывает подключение Google Диска как файлового хранилища Messenger и обработку данных при использовании этой интеграции. Контакт разработчика и владельца интеграции: makc.messenger.auth@gmail.com.

1. Назначение интеграции

Messenger Storage предназначен для хранения и получения файлов мессенджера: фотографий, видео, документов, голосовых сообщений и созданных для них превью. Google-аккаунт подключает владелец общего файлового хранилища. Пользователям Messenger не требуется предоставлять доступ к своим личным Google Дискам для отправки вложений.

2. Данные Google и разрешения

При подключении запрашивается разрешение https://www.googleapis.com/auth/drive.file. Оно позволяет создавать файлы и работать с файлами, созданными приложением или явно открытыми через него владельцем. В рамках этой работы обрабатываются содержимое таких файлов, их идентификаторы, имена, типы и размеры, а также связанные папки и технические метаданные.

Разрешение используется для файлового хранилища Messenger: загрузки, чтения, поиска и управления файлами. Данные Google Drive не используются интеграцией для рекламы или обучения моделей искусственного интеллекта.

3. Данные мессенджера

Сервер Messenger отдельно обрабатывает данные, необходимые для работы аккаунтов и общения: имя пользователя, почту, хеш пароля, заполненные поля профиля, сообщения, вложения, состав чатов и данные сеансов входа, включая IP-адрес, сведения об устройстве и время активности. Часть данных кэшируется на устройстве пользователя.

4. Хранение и доступ получателей

При включённом облачном хранилище файлы размещаются в подключённом Google Диске, а сообщения, идентификаторы файлов и их хеши — в базе данных сервера. Одинаковое содержимое может повторно использоваться несколькими сообщениями за счёт дедупликации.

Доступ к отправленным файлам определяется доступом к соответствующим чатам и сообщениям в Messenger. Получатели могут сохранить или переслать полученные файлы. Владелец подключённого Google Диска управляет файлами в своём хранилище и имеет к ним доступ.

5. Внешние сервисы

Облачная конфигурация использует Google Drive для файлов, Render для сервера, Neon PostgreSQL для базы данных, Upstash Redis для временных данных и GitHub Pages для веб-клиента. Данные, необходимые для соответствующих функций, обрабатываются этими сервисами в рамках их собственной инфраструктуры и правил.

Если пользователь запускает функции ИИ для задач, текст соответствующей задачи может передаваться DeepSeek для получения результата. Это отдельная функция Messenger; подключение Google Drive предназначено для файлового хранилища.

6. Срок хранения и удаление

Файлы в Google Диске хранятся до их удаления владельцем хранилища. Удаление сообщения в Messenger само по себе не гарантирует немедленного удаления физического файла: содержимое может использоваться другими сообщениями или сохраняться в хранилище.

Для запроса удаления относящихся к вам данных или отключения хранилища напишите на makc.messenger.auth@gmail.com. Укажите аккаунт и данные, о которых идёт речь, без передачи паролей или токенов доступа.

7. Отзыв разрешения Google

Владелец Google-аккаунта может отозвать разрешение Messenger Storage в настройках подключений Google. После отзыва сервер не сможет продолжать работу с Диском по этому разрешению. Уже сохранённые файлы останутся в Google Диске до их удаления владельцем.

8. Защита данных

Для облачных подключений используется HTTPS/TLS. Пароли аккаунтов Messenger хранятся в виде хешей. Данные авторизации Google используются сервером для доступа к файловому хранилищу. Обычные сообщения и вложения не следует считать автоматически защищёнными сквозным шифрованием: возможность обработки данных сервером и владельцем хранилища сохраняется.

9. Изменения и связь

При изменении способов обработки данных эта страница обновляется с указанием даты. По вопросам данных Google Drive, конфиденциальности и удаления обратитесь по адресу makc.messenger.auth@gmail.com.

Messenger Storage uses the Google Drive drive.file permission for app-created or explicitly selected files. Google Drive data is used for file storage and retrieval, not advertising or AI model training. The storage owner can revoke Google access and delete stored files. Contact the developer for data deletion requests using the email above.
